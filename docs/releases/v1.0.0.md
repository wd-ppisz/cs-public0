# cs-public0 1.0.0

First versioned baseline for scoped IPv4 inspection on a Linux bridge with
Suricata/NFQUEUE, explicit activation, systemd lifecycle and local/central
observability. The tag identifies one reviewed source commit from `main`.

## Included

- Guarded bridge selector and activation/withdrawal lifecycle.
- Alert-only default and explicit, separately reviewed selected-DROP opt-in.
- EVE logging/retention, Prometheus metrics and a Grafana dashboard.
- Optional compatible pinned engine profiles for GSO/copy correctness and an
  explicitly requested, kernel-verified netlink receive buffer.
- Queue/socket loss, accounting-gap and history reporting; unknown telemetry
  remains distinguishable from a healthy observation.
- A bounded observer refresh procedure that preserves the running sensor epoch.

Default installation remains non-activating. Supply and qualify your engine and
ruleset. No production signature feed or private operator inventory is included.

## Known security limitation — fail-open inspection bypass

Under queue pressure, fail-open can forward packets without inspection. A full
packet queue can do this before packet ID assignment and without increasing
kernel/user Drops. Exhaustion of the separate netlink receive buffer can also
lose delivery messages. Increasing the socket buffer is not a fix for packet-queue
saturation. Low average CPU, a healthy process, successful tests and zero current
Drops do not prove full inspection or capacity at peak traffic.

Keep monitoring, history, independent management and withdrawal available.
Measure latency/retransmissions and inspection separately under representative
load before expanding a deployment. Queue-depth, worker and rule-cost tuning
requires its own controlled qualification. Do not disable fail-open as an
automatic workaround. No CVE identifier is assigned by this release.

[NFQUEUE details](../nfq-receive-buffer.md),
[performance pitfalls](../performance-pitfalls.md) and

## Source distribution

Use the `v1.0.0` tag, not the moving `main` branch, to reproduce this release.
GitHub supplies source ZIP/tar archives for the tag. A separately attached source
tarball and SHA256 checksums identify the exact published asset bytes.
The release records the commit ID. The source archive is not a ready-to-run
engine package or evidence of a completed site-specific performance qualification.

Automation/documentation retain Apache-2.0; Suricata patch material and optional
engine components retain their separate GPL notices. Third-party rules are
operator-supplied. Created and maintained by [WebDisk](https://webdisk.io).
